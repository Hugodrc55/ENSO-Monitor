# ETL — réservé aux prochaines étapes

Ce dossier accueillera le traitement Python des données NOAA ONI ERSSTv6.
Au Jour 1, aucun téléchargement scientifique, transformation, import ou accès
à PostgreSQL n'est implémenté.

L'étude de la source est prévue au Jour 2, la transformation au Jour 3 et
l'import avec provenance et contrôle des doublons au Jour 5. Chaque étape
nécessite la validation de l'étudiant.
